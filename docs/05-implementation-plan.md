# 实施计划

工期仅作为单人+AI 的拆分参考，总计约 10–15 个工作日，外部授权等待另计。每阶段产出可独立验证的成果，不一次性生成所有页面后再补后端。

| 阶段 / 任务 | 依赖 | 产出 | 完成门槛 |
|---|---|---|---|
| 0 / T00 合宙协议验证 | 无 | 教程附件摘要、正常登录记录、脱敏接口fixture、独立站/托管决策 | 真实登录和设备读取成功；否则外部部分 blocked |
| 1 / T01 工程基线 | 无 | Svelte/Go目录、锁版本、统一UI、Make入口、OpenAPI骨架、CI | 构建/类型检查通过，最小页面与健康API可运行 |
| 2 / T02 数据库与迁移 | T01 | 完整表迁移、应用角色、扩展/许可兼容验证 | 临时库全新迁移成功、再执行无破坏、组合FK/索引检查 |
| 3 / T03 RaceBox导入 | T02 | dry-run/限量/断点导入CLI、单位核验报告 | 有限样本两次导入不重复、原库只读、时间/单位明确 |
| 4 / T04 本地完整链路 | T02 | MQTT ingestor、模拟发布器、鉴权API、SSE | 消息→落库→设备列表；重复/乱序/DB中断测试通过 |
| 5 / T05 地图与轨迹 | T03,T04 | 地图工作台、列表联动、历史查询/回放、移动端 | 真正读取本库数据，无定位/断线/底图失败均可用 |
| 6 / T06 合宙真实接入 | T00,T05 | Provider adapter、官方登录入口、真实设备/轨迹 | 活动账号成功登录，设备数与官方同期对照，session过期测试 |
| 7 / T07 Compose交付 | T04,T05 | compose.yaml、compose.standalone.yaml、Dockerfile、初始化/备份脚本 | 两种部署冷启动、重启保持数据、健康检查、备份恢复 |
| 8 / T08 围栏报警 | T05,T07 | P1服务端围栏、幂等报警、审计 | 网页关闭后消息触发报警、边界抖动/乱序不误报 |
| 9 / T09 总体验收 | T06,T07 | 验收报告、截图、许可证清单、演示说明 | P0全部过关，活动条件有真实证据，明确P1实现范围 |

关键路径：本地 T01→T02→T04→T05→T07；活动额外依赖 T00→T06。T00 外部阻塞时继续本地工作，不把整个项目标完成。T08 不阻塞 P0，但宣传围栏功能前必须完成其验收。

T00 浏览器检查只读：打开官方站→登录用户提供账号→项目/设备/位置/历史→退出。不要发指令、删除设备或改配置。遇验证码/短信保留当前状态，记录需要用户的具体操作。不要把用户提供账号密码写回文档。

每个任务至少一次失败路径检查，完成后更新 TASKS 和 PROGRESS。更改 schema/协议/UI 数据定义时同步更新 OpenAPI/JSON Schema/fixture。先测小样本，再做10万点/1000设备压测；不能向原库写测试数据。
