# 验收矩阵

所有项目初始为未验证。报告必须区分本地模拟、RaceBox真实历史、合宙在线账号数据。

| ID / 需求 | 操作 | 预期与证据 |
|---|---|---|
| A01 / R01 | 正确/错误密码、退出、会话过期 | 正确登录；错误统一提示；旧会话不能访问API |
| A02 / R02 | 在官方流程登录活动账号 | 真实成功回调，设备来自该账号；不能用本地同名账号替代 |
| A03 / R03 | 同期对照官方设备列表和本系统分页 | 数量/标识/状态相符；未知和同步中断不伪报在线 |
| A04 / R04–05 | 点击列表/地图，筛选，无GPS设备 | 联动准确；无定位不落0,0；缺电量显示未知 |
| A05 / R06 | 发已知坐标MQTT，刷新浏览器 | DB→API→SSE→地图一致，时间和经纬顺序正确 |
| A06 / R06 | 相同消息重复10次、冲突载荷、晚到消息 | 单条历史；冲突隔离；旧定位不覆盖最新 |
| A07 / R06 | DB暂时不可达/ingestor在提交前后崩溃 | 恢复重投无丢失已确认事件、无重复业务效果 |
| A08 / R07 | 查询历史窗口、抽稀、播放/暂停/拖动 | 时间顺序、断段、起终点正确；无数据有提示 |
| A09 / R08 | 先dry-run，再有限导入，重跑/断点恢复 | 原库只读，幂等，速度未知不乱换算，历史不冒充实时 |
| A10 / R09 | 外置PG/全容器冷启动和重启 | 健康、迁移成功、卷持久；无手工进容器改配置 |
| A11 / 安全 | viewer写操作、跨租户详情/轨迹/SSE | 拒绝越权，响应不泄漏数据；无token/密码日志 |
| A12 / 实时 | SSE断开重连、游标过期 | 补发或resync，无永久漏更新 |
| A13 / UI | 390×844与1440×900，键盘/深色 | 无横向溢出，触控可达，焦点清楚，错误能恢复 |
| A14 / 性能 | 指定基线执行10分钟负载 | 报p50/p95/失败率/积压；不向合宙压测 |
| A15 / 地图 | 已知WGS84点、不同底图、底图失败 | 无二次坐标偏移；保留归属；失败仍可用列表 |
| A16 / R11 P1 | 网页关闭，跨围栏、抖动、晚到点 | 服务端报警，转换幂等；历史导入默认不触发实时报警 |
| A17 / 运维 | 备份恢复到隔离库、迁移失败 | 数据可查询，失败阻止业务，未碰原库 |

最低自动化：Go单测（验证/幂等/单位与时间转换/权限），真实PG与Mosquitto集成（事务+重投），前端类型检查，Playwright端到端（登录、地图列表、轨迹、移动端、过期）。视觉截图不得包含未经脱敏的真实轨迹与凭据。

“超过对标”提交材料：三分钟演示登录→找设备→状态→地图→轨迹→手机布局；同操作步骤和响应时间对照表；明确已知限制。不能因为UI好看而省略A02/A03。发布到企业微信群需要用户自行操作或另行明确授权。

完成定义：P0功能+对应验收通过、依赖/镜像锁定、许可证清单、可部署命令、无密钥入库、PROGRESS留有真实命令记录。外部联调未完成时只能称“本地平台完成，活动验收阻塞”。
